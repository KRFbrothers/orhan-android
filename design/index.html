Design system

Bottom navigation

The shipped app has 5 destinations — OrhanTab in HomeScreen.kt: Chats, Agents, Discover, Memory, Artifacts. This mockup renders those 5 plus Profile as a 6th tab so the Profile screen stays one tap away on mobile. 80px bar, one 48px+ target per item, M3 active indicator pill, on all 6 main screens.
