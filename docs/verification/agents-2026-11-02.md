### Stable identity follow-up

AgentStore format v4 stores an immutable agent ID; v1-v3 records derive a deterministic UUID from their original name and creation time. Editing/renaming retains that ID. Workflow format v2 stores an optional agent ID and reads v1 workflows without one. Chat thread format v5 stores an optional agent ID; v1-v4 readers preserve prior content and handoff state. Legacy chat/workflow records acquire an ID when first opened while their saved name still identifies a current agent. A rename operation also associates old-title chats and workflow references with the renamed ID without changing message history or prompt content. There is no destructive history rewrite. An already-renamed legacy title that predates ID association, or a deleted agent ID, remains unresolved rather than being mapped to a possibly different persona.

Agent-thread retries persist selected tools in chat thread v6, while v1–v5 reads remain supported.
