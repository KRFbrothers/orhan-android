- `feature/chat/AgentInstructionsBlock.kt`: legacy tool selections are kept out of direct and handoff chat prompts. Only the agent name and instructions are included. The editor reports that there is no per-agent allowlist in the request contract and no capability catalog to confirm whether Web, Files, Code, or Image are globally available.

Existing v1/v2 configurations, including unknown labels, remain intact and round-trip through the existing store. No legacy tool labels are sent in chat prompts.
